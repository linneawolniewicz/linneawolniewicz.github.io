Overleaf project: https://www.overleaf.com/project/6324d08ddd94f7578b1cb3e0

Build from this directory with XeLaTeX (twice for references) or `tectonic resume.tex`. The supplied template uses Times New Roman; Roboto header fonts are included. After inspecting the rendered PDF, copy it to `../Resume_Linnea_Wolniewicz.pdf`. The website excludes this source directory.
