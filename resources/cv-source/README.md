# Curriculum vitae source

Overleaf project: https://www.overleaf.com/project/658f05c92e272b6ca2ae968c

Build from this directory with XeLaTeX (twice for references) or `tectonic cv.tex`. The supplied template uses Times New Roman; Roboto header fonts are included. After inspecting the rendered PDF, copy it to `../Curriculum_Vitae_Linnea_Wolniewicz.pdf`. The website excludes this source directory.
